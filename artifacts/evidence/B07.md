## 实现要点

- 卸货沿 -x 抽出：扫掠 x 区间 [0, x+L] 与箱体 y/z 区间，严格正交集才算阻挡（面接触不阻挡）。
- 每步按 (z 降序, x 升序, id 升序) 选可取箱；不可取（承托依赖/阻挡）则整站报 UNLOAD_BLOCKED，不临时搬后站货。
- 装货指引 = 卸货逆序；validate_loading_steps 从空车逐步沿 +x 放入，检查路径无阻挡且承托成立。
- validate 检查次序（不跳站、不回退）、完整性（无重复、无遗漏）与每步可取性。

## 限制与说明

- 卸货与装货的扫掠路径对称（同为 [0, x+L] 区间），符合 A3 约定。
- 超载、指标篡改、分配完整性等由 B08 组合校验器覆盖，本卡只做卸货/装货。
