## 操作步骤
1. 显示车厢线框、后门标签和箱体；按门店着色，易碎箱有图例。
2. 旋转90度交换长宽，最小角转中心坐标；mm→m与z向上转换统一在一个函数中。
3. 支持旋转视角、重置视角、箱件点击查看信息；释放旧场景资源，切车不重叠残留。
4. 用成功样例检查上下两箱位置、车门方向和尺寸比例。
