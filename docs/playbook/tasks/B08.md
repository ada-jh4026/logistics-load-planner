## 操作步骤
1. 实现validate_solution(request,result)，先检查分配/门店/车辆完整性，再调用时间、几何、卸货校验。
2. 独立重算metrics并比较，浮点字段按1e-6容差；输入valid=true也不能跳过检查。
3. 提供内部validate_vehicle_candidate助手，以便packer/repair复用已约定约束，但不依赖求解器。
4. 测试正常样例和逐项篡改；允许全部unassigned的部分计划，但禁止漏箱。

未通过时保留已完成工作和错误证据，标in_progress或blocked；依赖未完成的后继卡不能标done。
