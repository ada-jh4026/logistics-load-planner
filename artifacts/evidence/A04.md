# A04 方案对比叙述与装卸作业单 —— 验收证据

日期：2026-10-10（英国时间 17:10）。执行者：前端/智能体线（Claude Code）。

## 实现
- `agent/compare.py`：全部 12 项 metrics 的 baseline / candidate / delta；按 EVALUATION 口径判定 `same_served_set`（两方案已服务门店集合）、`both_valid`（两方 validation.valid）、`comparable_cost`（前两者且基线费用 > 0）；不可比时 `cost_change_rate=null`。文本先说覆盖变化再说费用；模型模式下除数字核对外，还检查「不可比却给出费用变化百分比」，命中则重试，仍不合格回退模板。
- 装卸作业单：`POST /agent/explain` `focus=unload`。模板按车辆、按到站顺序逐步列出箱件，标注易碎；装货指引为卸货逆序，措辞与 D05 一致（最后卸的最先装、靠车头；最先卸的最后装、靠后门）。
