# A02 接入 DeepSeek 并实现证据绑定解释 —— 验收证据

日期：2026-10-10（英国时间 15:40）。执行者：前端/智能体线（Claude Code）。

## 实现
- `agent/llm.py`：`OpenAICompatLLM`（openai SDK，`base_url` 默认 DeepSeek，`timeout` 与 `max_retries=1`）；`NullLLM`（无密钥）；`FakeLLM`（测试注入，记录提示词）。
- `agent/grounding.py`：提取时刻 HH:MM、百分数、带单位数字；序号、步骤号、实体 ID 中的数字不算事实数字。带单位的数字只在同类事实路径里匹配（元→cost，km→distance，kg→weight，分钟→*_min，箱/辆/站/家/处→对应计数），无单位数字在全部事实里匹配。允许四舍五入到 0 或 1 位小数。
- `agent/explain.py`：提示词只含 focus 要求 + 事实表 JSON（不含坐标）；首轮核对不通过 → 带未匹配数字重试一次 → 仍不通过回退模板并写 warnings；任何异常回退模板。响应 `mode` 如实反映生成方。

- FakeLLM 首轮「150 元」、重试「120 元」→ mode=llm，warnings 记录「重试后通过」。
- FakeLLM 抛 TimeoutError → mode=template，HTTP 层不报错。
