# A01 建立智能体服务骨架与模板解释 —— 验收证据

日期：2026-10-10（英国时间 15:40）。执行者：前端/智能体线（Claude Code）。

## 环境
- 根目录 `.venv` 由 `uv venv .venv --python 3.12` 创建（之前不存在；主线 B01 可直接复用，再往里装后端依赖即可）。
- 实际安装并锁定在 `agent/requirements.txt`：fastapi 0.143.0、uvicorn 0.54.0、pydantic 2.14.0、httpx 0.28.1、openai 3.28.0、python-dotenv 1.2.1、pytest 9.0.2。
- 未改根目录 `requirements.txt`（主线所有）。

## 实现
- `agent/schemas.py`：CONTRACT v0.1 的 pydantic 镜像（SolveRequest / JobResponse 全字段，`extra="forbid"`），以及 ExplainRequest / ExplainResponse / Health / 错误外壳。
- `agent/facts.py`：事实表推导。单车体积与载重利用率、每站等待与松弛时间按 request 独立重算。
- `agent/templates.py`：overview / unassigned / vehicle / unload 四种模板文本。
- `agent/app.py`：`GET /agent/health`、`POST /agent/explain`；422 统一错误外壳；CORS 只放行 5173。
- `agent/config.py` + `agent/.env.example`：密钥与模型配置，缺密钥进入模板模式。

## 实际运行
```
.venv\Scripts\python.exe -m pytest -q agent/tests      → 18 passed
.venv\Scripts\python.exe -m uvicorn agent.app:app --host 127.0.0.1 --port 8001
curl http://127.0.0.1:8001/agent/health
  → {"status":"ok","schema_version":"0.1","llm":{"provider":null,"model":null,"configured":false}}
curl -X POST /agent/explain  (request-partial + response-partial, focus=overview)
  → mode=template, grounding={checked_numbers:25, unmatched:[], passed:true}
    文本含「部分配送」「总费用 120 元」「等待 10 分钟」「S02（1 箱）：箱件尺寸超过所有车厢」
curl -X POST /agent/explain  (focus=unload, vehicle_id=V01)
  → 作业单：到站 S01：1. 取出 B02（易碎…） 2. 取出 B01；装货按逆序
curl -X POST /agent/explain  (response-failed)        → HTTP 422 INVALID_INPUT
```
事实表断言（`agent/tests/test_facts.py`）：success 样例费用 120、体积利用率 0.5、载重利用率 0.3、S01 等待 10 分钟、松弛 100 分钟；partial 样例 S02 未分配 BOX_TOO_LARGE。与 ACCEPTANCE C01 手算一致。

## 限制
- 服务为单进程、无状态；不保存任何请求。
- 坑：Windows 上用 `print` 把 JSON 写文件默认 GBK，curl 发给服务会解析失败；测试脚本已改为显式 UTF-8 写文件。
