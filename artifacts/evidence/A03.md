# A03 自然语言指令到受控补丁 —— 验收证据

日期：2026-10-10（英国时间 17:10）。执行者：前端/智能体线（Claude Code）。

## 实现
- `agent/interpret.py`：IntentOp（按实体 ID）→ 下标解析 → RFC 6902 补丁 → 协议模型与范围校验。逐个操作应用，失败进 `rejected_ops` 并附中文理由，其余继续；补丁路径在每一步的当前状态上解析（连续移除车辆时下标正确）。白名单：depot.departure_min；stores[id].window_start_min / window_end_min / service_min；boxes[id].fragile / allow_rotate_xy；options.method / seed / time_limit_ms / max_iterations / speed_kmph；remove_vehicle（至少保留一辆）；add_vehicle（ID 不重复）。
- `agent/rules.py`：规则解析器（模板模式）。覆盖最早/最晚收货时间、服务时长、车辆不可用、新增同款车、易碎/旋转标记、时间预算、车速、求解方法、种子、迭代、仓库出发时间；指向不存在实体时生成会被拒绝的占位操作，让用户看到「S99 不存在」。
- `agent/timeparse.py`：「14:00」「下午两点」「9 点半」「晚上八点二十」「840」统一为分钟。
- 模型模式：系统提示要求只输出 intent_ops（按 ID，不写下标、不写完整请求）；`json_object` 模式；解析失败回退规则模式。发给模型的实体清单不含坐标。
- `agent/scripts/eval_interpret.py`：对测试集逐条真实调用并统计。

## 限制
- 规则模式只覆盖测试集句式；复杂表达需模型模式。
- 不做多轮对话；每次指令独立。
