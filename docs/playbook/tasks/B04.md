## 操作步骤
1. 实现distance_km(a,b)、travel_min(a,b,speed)、schedule_route(request,vehicle_id,store_ids)。
2. schedule_route包含等待、服务及回仓，返回实际时间和违规；不能只比较arrival。
3. 实现compute_metrics(request,routes,unassigned)，重新计算费用及分母；空计划按协议输出null/0。
4. 用C01手算数值断言，C03测试时间窗边界；测试未用车辆不参与利用率分母。
