# F03 按真实坐标渲染车厢和箱体 —— 验收证据

日期：2026-10-10。执行者：前端/智能体线（Claude Code）。

## 实现
- `frontend/src/lib/geometry.ts`：唯一的坐标转换点。业务 (x, y, z) mm → 场景 (x, z, y) / 1000 m；旋转 90° 交换长宽；中心 = 最小角 + 半尺寸。
- `frontend/src/components/CargoView.tsx`：车厢线框 + 地板；后门 x=0 处用码头黄黑斜纹门槛标记，并有「后门 x=0」「车头」精灵标签；箱件按到站顺序着色（`palette.ts`，分类色已用校验脚本验证），易碎箱红色描边；图例说明后门、易碎、颜色含义。
- 交互：OrbitControls 拖动旋转、滚轮缩放；「重置视角」按钮；点击箱件在右栏显示尺寸、重量、易碎、旋转、最小角坐标；点击空白取消选择。
- 切换车辆时以 `key` 重建相机，箱件 mesh 随 route 变化卸载，无残留。

## 验证
- `npm run build` 通过。
- 截图：`artifacts/evidence/screenshots/F03_success_3d.png`（success 样例）。核对：B01 在 (1000, 0, 0)，B02 在 (1000, 0, 1000)，两箱上下紧贴、不悬空；B02 为易碎（红色描边）在上；车厢 2 × 1 × 2 m 比例正确；后门斜纹在 x=0 一侧，车头标签在 x=2 m 一侧。
- 切换到 partial 样例再切回，布局随 JSON 更新。

## 限制
- 标签为画布精灵，缩放时大小随视距变化。
- 未做平滑动画（按 D04 可延期）。
