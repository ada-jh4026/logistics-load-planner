# B01 建立可复现的后端骨架

状态以board.json为准。本卡是待实现要求，不是已完成报告。

## 前置条件
无代码依赖，可以立即领取。 预计30分钟；超出时间先缩减非必要工作并记录阻塞。

## 必读材料
- DECISIONS.md
路径默认相对docs/playbook；明确写项目根目录者除外。只读相关段落，无需重读全部聊天。

## 修改范围与交付
- backend/__init__.py
- backend/app.py
- requirements.txt
- requirements-dev.txt
- tests/test_health.py
若需要改相邻公共模块，先检查已有实现与他人修改，仅改完成本卡所需范围。

## 操作步骤
1. 确认python --version、node --version和可用包管理器；记录真实版本到docs/environment.md。不要删除既有环境。
2. 创建项目内.venv；使用.venv的Python安装Web与测试依赖，锁定实际版本。核心不引入求解器重型依赖。
3. 实现GET /api/health，并写健康接口测试；创建.gitignore忽略环境、凭据、缓存和生成的大文件，保留可复现小样例。
4. 在8000端口启动并通过HTTP读取健康结果；记录Windows启动命令。

## 验证命令或操作
.\.venv\Scripts\python.exe -m pytest -q tests/test_health.py
以上是实现后应实际执行的目标命令。若文件尚未创建，先实现，不能将命令不存在记为通过。Windows主线默认用项目.venv的Python；不同平台使用相应虚拟环境解释器并记录实际命令。

## 完成标准
健康接口返回协议版本0.1；能从根目录启动服务；保存环境版本与真实测试输出。
保存artifacts/evidence/B01.md，填写执行命令、真实结果、相关输出文件及限制。此文件由执行本任务者创建，目前并不存在。满足标准再更新board.json为done。

## 失败处理
环境安装超过45分钟仍失败，记录缺失组件与错误；不转为假接口或下载未知可执行文件。
未通过时保留已完成工作和错误证据，标in_progress或blocked；依赖未完成的后继卡不能标done。
