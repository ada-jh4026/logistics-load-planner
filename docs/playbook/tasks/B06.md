## 操作步骤
1. 实现oriented_size、intersects、inside_vehicle、find_support、validate_layout基础函数。
2. 仅旋转xy；正体积交集才是碰撞；尺寸/坐标均按mm。
3. 地板直接支持；高处必须单箱完整承托；底箱易碎时报FRAGILE_LOAD。
4. 测试刚好贴边、1mm重叠、浮空、越界、跨两箱支撑、旋转禁止；输出定位到box_ids。
