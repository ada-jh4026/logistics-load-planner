## 操作步骤
1. 在根目录 `.venv`（若尚不存在则创建）安装 fastapi、uvicorn、pydantic、httpx、openai、pytest，锁定实际版本到 agent/requirements.txt。不改 requirements.txt（主线所有）。
2. 用 pydantic 按 CONTRACT.md 写 SolveRequest / JobResponse 镜像模型；非法输入返回 422 统一外壳。
3. 实现 FactSheet 推导（单车利用率、等待/松弛时间独立重算）；对 response-success / response-partial 两个样例写断言（费用 120、体积利用率 0.5、S02 未分配 BOX_TOO_LARGE）。
4. 实现四种 focus 的模板解释（无模型）；GET /agent/health 返回 configured=false。
5. 在 8001 端口启动并用 HTTP 调用 explain；记录 Windows 启动命令。
