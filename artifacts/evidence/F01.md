# F01 搭建前端及协议类型 —— 验收证据

日期：2026-10-10（英国时间 14:40）。执行者：前端/智能体线（Claude Code）。

## 实际技术栈
- Node v22.14.0，npm 10.9.2（`node -v` / `npm -v`）。
- Vite 8.3.0，React 19.2.8，TypeScript 6.0.2，@react-three/fiber 9.8.1，@react-three/drei 10.7.9，three 0.186.1，zod 4.6.5，@fontsource/barlow 5.3.0。版本来自 `frontend/package.json`，锁文件 `frontend/package-lock.json` 已提交。
- 脚手架：`npx create-vite@latest frontend --template react-ts`，之后删除模板资源。

## 协议与样例
- `frontend/src/protocol/contract.ts`：按 CONTRACT.md v0.1 用 zod 定义 SolveRequest / JobResponse / Result / Metrics / 错误外壳，类型由 schema 推导，不另写字段。
- `frontend/src/lib/mock.ts`：直接 `import` `docs/playbook/examples/*.json`（Vite `server.fs.allow: ['..']`），加载时用 schema 校验；五个样例全部通过校验。
- 页面顶栏在 `is_mock=true` 时显示「演示数据」标记，`data_source=synthetic` 时显示「模拟数据」标记。

## 实际运行
```
cd frontend && npm install        # added 91 packages
cd frontend && npm run build      # tsc -b && vite build → ✓ built（dist/ 生成）
cd frontend && npm run dev        # VITE v8.3.4 ready, http://127.0.0.1:5173/
```
退出码均为 0。构建有一条「chunk > 500 kB」提示（three.js 体积），不影响运行。
