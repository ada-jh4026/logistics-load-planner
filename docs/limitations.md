# 当前限制与适用边界

与 README 第 7 节一致，这里按层展开，供评审与后续迭代对照。

## 业务模型
- 单仓出发并回仓，单日，每辆车只跑一趟；门店不拆车、不重复访问。
- 货物为长方体箱件；只允许绕竖直轴 0° / 90° 旋转，不允许翻转。
- 门店时间窗固定，提前到达等待，迟到视为不合格；不建模收货排队与装卸人力。
- 不建模多仓、多日、取货、冷链温层、司机排班、动态插单。

## 几何与装载
- 承托规则保守：箱件落地或由**单个**非易碎箱顶面完整托住；不支持跨两箱桥接、重心、振动、材质抗压。
- 车厢视为空长方体：门口为完整截面，无门框、轮包、绑扎点。
- 配载是确定性启发式，候选位置有上限；「未找到布局」记为 SEARCH_EXHAUSTED，不等于数学上不可行。体积利用率不代表空间最优。
- 卸货只允许沿后门方向水平抽出；不允许临时搬出后站箱件再放回。

## 网络与时效
- 门店间距离为平面欧氏距离，行驶时间按固定车速换算；不是道路网络，没有路况。
- 费用 = 车辆固定启用费 + 单价 × 里程；不含油耗、人工、过路费等未建模项。

## 求解
- 路线构造为贪心 / 插入 + 2-opt，不是精确解；协同修复为有限候选（移单到已有车或新车），受时间预算与迭代上限约束。
- 在当前基准数据上装载从未失败，协同修复未被触发；其作用只由单元测试案例证明。
- 路线构造曾因费用比较口径问题多开车辆，已修正（提交 31e9a54）并重跑基准；修正前的记录保留在 `artifacts/benchmarks/{small,latest,stress}/`，不再适用于当前代码。

## 智能体
- 解释只依据事实表；模型无法回答事实表之外的问题。
- 指令为单轮，无对话记忆；可改字段限白名单（时间窗、服务时长、易碎、旋转、求解选项、增减车辆）。
- 数字核对基于文本提取，极端措辞（如把费用写成「一千二」）不会被识别为数字，也不会被核对。
- 规则模式只覆盖测试集句式。

## 服务与工程
- 任务为内存存储，单工作线程串行求解，队列上限 8，重启丢任务。
- 无认证、无多租户、无审计日志；CORS 只放行本地前端。
- 前端 3D 为即时切换，无过渡动画；大规模（>8 站）车辆按单色深浅着色。

## 数据
- 全部为模拟数据；手工界面样例标 `is_mock=true`；没有任何企业真实数据。
- 真实场景参数（车厢结构、堆叠层数、门店作业时长）需晋级后用真实数据标定。
